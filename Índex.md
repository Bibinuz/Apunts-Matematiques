# Grau de Matemàtiques — Índex General

Benvingut/da al **Repositori Centralitzat d'Apunts del Grau de Matemàtiques** a la **Universitat Autònoma de Barcelona (UAB)**. Aquest espai conté tots els apunts teòrics, teoremes, lemes, demostracions rigoroses i exemples extrets i transcrits de les classes presencials, estructurats per cursos acadèmics.

### 1. [[Índex - 1r Curs|Primer Curs]]
Assignatures troncals i formació bàsica de primer any:
- **[[Índex - Àlgebra 1|Àlgebra Lineal 1]]:** Sistemes d'equacions lineals, matrius, determinants i espais vectorials.
- **[[Índex - Fonaments 1|Fonaments de les Matemàtiques 1]]:** Lògica, mètodes de demostració, teoria de conjunts, ordres i equivalència.
- **[[Índex - Funcions 1|Funcions de Variable Real 1]]:** Nombres reals, completesa, cardinalitat de Cantor, successions i criteris de límits.
- **[[Índex - Mecànica Clàssica|Mecànica Clàssica]]:** Cinemàtica vectorial 2D/3D, dinàmica newtoniana i centres de masses.

## Pautes de Navegació a Obsidian

> [!TIP] Com moure's ràpidament
> - **Cerca global ràpida:** Prem `Ctrl + O` (o `Cmd + O` a macOS) per obrir qualsevol nota directament escrivint el seu nom.
> - **Vista de graf (*Graph View*):** Prem `Ctrl + G` per explorar visualment com es connecten els conceptes entre assignatures i cursos.
> - **Compilació del Llibre:** Pots generar un document HTML / llibre complet amb el script `python3 scripts/generar_llibre.py` (admet opcions per filtrar per curs o assignatura). Obrint aquest fitxer html en el navegador pots descarregar el llibre com a **PDF**.
> - **Afegir nous apunts:** Consulta el document guia situat a l'arrel: [`GUIA_APUNTS.md`](GUIA_APUNTS.md).
